# Privacy Policy

Satoshillo processes visible webpage text locally to detect fiat prices and display their value in satoshis. Page content, browsing history, selections, and detected prices are not collected, stored, or transmitted.

Local HTML files are processed only when the user explicitly enables the browser's option to allow access to file URLs.

The extension excludes form fields, text areas, selectors, content-editable elements, and controls identified as textboxes, searchboxes, or comboboxes from price scanning.

Satoshillo connects only to these public market-data providers:

- Yadio
- Kraken
- ExchangeRate-API
- Binance
- FXRatesAPI

These requests contain no page content or current-page URL. As with any direct web request, the provider may receive the user's IP address and standard connection metadata.

The extension stores the following data locally in the browser:

- Cached BTC/fiat exchange rates and their update time.
- The origins of sites where the user has disabled Satoshillo.

This local data is not synchronized or sent to the developer. Satoshillo does not include analytics, advertising, tracking, telemetry, or remotely hosted code.
